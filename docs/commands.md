| brightness বাড়াও | increase brightness | Increase screen brightness |
| brightness কমাও | decrease brightness | Decrease screen brightness |
| PC বন্ধ করো | shutdown | Shutdown computer |
| restart করো | restart | Restart computer |
| lock করো | lock | Lock computer |
| sleep করো | sleep | Put computer to sleep |
| screenshot নাও | screenshot | Take screenshot |

## Conversation

You can also just talk to Nahin naturally:
- "তুমি কেমন আছো?" (How are you?)
- "আজকের আবহাওয়া কেমন?" (What's the weather today?)
- "সময় কত বলো তো?" (What time is it?)

## Tips

1. **Be Clear**: Speak clearly and wait for response
2. **Short Commands**: Keep commands brief (1-2 sentences)
3. **Wake Word**: Say "Hey Nahin" to activate, or use F13 for push-to-talk
4. **Bilingual**: Mix Bengali and English as you prefer
